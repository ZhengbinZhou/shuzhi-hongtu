# 数智-红途本地运行说明

## 环境要求

- Node.js 22.13.0 或更高版本
- npm（随 Node.js 安装）

## 本地开发运行

### Windows / PowerShell

在代码包根目录打开 PowerShell，执行：

```powershell
.\scripts\dev-local.ps1
```

这个脚本会自动寻找本机 Node.js；如果系统 PATH 中没有 `node`，会优先使用 Codex Desktop 自带的 Node.js 和 pnpm。首次运行会自动安装依赖，然后启动本地开发服务。

如需指定端口：

```powershell
.\scripts\dev-local.ps1 -Port 5174
```

如果依赖已经安装，只想直接启动：

```powershell
.\scripts\dev-local.ps1 -SkipInstall
```

如果依赖安装中断或升级过依赖，需要强制重新安装/重建：

```powershell
.\scripts\dev-local.ps1 -ForceInstall
```

### macOS / Linux / 已配置 Node.js 的环境

```bash
npm install
npm run dev:local
```

终端显示访问地址后，用浏览器打开即可。

## 生成部署版本（macOS / Linux）

```bash
npm run build
```

## 重新生成单文件 HTML

```bash
npm run export:html
```

命令完成后，项目根目录会生成 `数智-红途-离线完整版.html`。主页面仍内嵌原有功能代码和44张点位图片；“历史足迹”专题还会读取同目录下的 `history.html`、`history-*.js`、`history-*.css` 与 `important/` 素材，因此分发时需要保留这些配套文件。

## 主要目录

- `app/page.tsx`：页面内容、点位数据、路线匹配与交互逻辑
- `app/globals.css`：页面全部样式
- `app/jiangxi-map.ts`：江西省地图基础数据
- `app/jiangxi-counties.ts`：县级行政区数据
- `public/landmarks/`：44张点位宣传图
- `history.html`：循着历史的足迹专题页面
- `history-data.js`：四章史实、点位、问答与引用资料
- `history-entry.js`：主页面入口及历史路线规划衔接逻辑
- `important/`：历史专题实际使用的视觉素材
- `standalone/`：单文件 HTML 导出工具
- `docs/44-point-image-audit.md`：点位图片核验记录
