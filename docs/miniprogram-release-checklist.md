# 微信小程序发布检查清单

## 一键验收

在项目根目录运行：

```powershell
npm run verify:miniprogram
```

该命令会依次完成 TypeScript 检查、微信小程序生产构建、专项测试和发布包审计。发布审计要求主包不超过项目设定的 2 MiB 阈值，并确认 44 张点位图全部进入 `miniprogram/dist/landmarks/`。

## 开发者工具验收

1. 在微信开发者工具中导入项目根目录，不要单独导入 `miniprogram/`。
2. 确认项目入口为 `miniprogram/dist/`，自动热重载保持关闭。
3. 运行一键验收后点击“编译”；若仍显示旧代码，完全退出开发者工具后重新打开项目。
4. 控制台不得出现 `MiniProgramError`、`TypeError` 或页面注册失败。

## 核心流程

- 首页能看到完整 44 张真实点位图，并可横向滑动。
- 首页能看到 44 个点位的内嵌总览地图，点击地图标记可进入点位详情。
- 规划页四个基础选择保持 2×2 排布，能生成推荐路线。
- 生成结果可以“保存路线”，并在“我的”页面再次打开和删除。
- 路线详情可记录完成进度，关闭再打开后进度仍存在。
- 路线详情能显示多点连线地图、路段里程/耗时、匹配维度，并可上移、下移、替换或删除非核心点位。
- 编辑后的路线通过收藏或分享链接再次打开时，点位顺序与内容保持一致。
- 点位图鉴支持区域筛选、关键词搜索、详情展开和“地图查看”；完整详情页包含地址、开放时间、预约方式、资料核验、全部主题维度及同区域点位。
- 历史专题包含四个阶段、地图、事件时间线、研学问答、资料来源，并可带入专题规划条件。
- 方法论页面完整说明可行性过滤、内容匹配、历史叙事校验、差异化输出和数据边界。
- 住宿及包车入口会复制外部检索链接；受小程序业务域名限制，不在未配置域名的 `web-view` 内直接打开。
- 路线详情页的“分享”按钮能调起微信原生分享面板。
- “生成路线海报”可以预览并保存到相册；首次保存时正确处理系统相册权限。

## 审核前人工确认

- 在微信公众平台补齐小程序名称、头像、服务类目、隐私保护指引和用户协议。
- 当前仅向 `openLocation` 传入项目内已有点位坐标，不读取用户实时位置；若以后新增 `getLocation` 或位置选择能力，需要同步补充隐私接口声明。
- 开放时间和交通时间仍属于演示数据，审核文案及正式运营前应以场馆公告为准。
- 真机至少覆盖一台 iOS 和一台 Android 设备，检查图片、Picker、地图和分享能力。
- 上传前确认版本号和项目备注，不要直接使用“测试版”文案提交正式审核。

## 平台差异说明

网页端“打印 / 导出 PDF”在小程序端对应为“生成路线海报”；网页外链在未配置小程序业务域名时对应为“复制链接”。其余已迁移功能应按本清单逐项真机验收。代码构建与测试不会代替管理员在微信公众平台提交审核。
