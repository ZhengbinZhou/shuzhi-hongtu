# “数智-红途”44个点位宣传图核验表

## 核验原则

1. 每个点位至少检索3张候选实景照片，先排除同名景点、效果图、室内无关照片和搜索误匹配。
2. 建筑类重点核对屋顶形式、层数、立面比例、门窗位置、院墙及标志性构件；纪念碑与雕塑类重点核对碑体轮廓、基座和主体组合；步道、渡口、村落类核对真实地形和现场设施。
3. 旧版44张图均没有逐图照片来源记录，不能证明其真实性，因此本轮全部重新制作。普通点位采用实景照片的确定性描线转换，避免生成模型改变建筑；八角楼和大井毛泽东同志旧居另外使用高保真参考图重绘并人工复核。
4. 统一输出为800×520横向画幅、连续米白底、深红单色线描；不再使用方形内框，也不再以“同类建筑”代替真实点位。

## 重点纠错

- **茅坪八角楼**：旧图错误画成八角亭式楼阁。真实建筑是土木结构、悬山顶、小青瓦的两层民居，“八角”来自楼上八角形天窗。本轮按真实入口、砖墙、木构、门窗和屋面重绘。
- **小井红军医院旧址**：旧图画成低矮单层院落。真实主体为两层木质建筑，正面有连续外廊。本轮按真实全景重绘。
- **大井毛泽东同志旧居**：旧图为概念化民居组合。真实地标是长条白墙、深色木构、灰瓦建筑，并与古树、读书石共同构成识别画面。本轮按实景重绘。
- **中共赣南省委旧址**：真实旧址利用于都县城原天主教堂，立面具有教堂山墙、圆窗和拱券特征，不能画成普通赣南祠堂。
- **路线型点位**：挑粮小道、祁禄山红军小道、长征历史步道均采用实际路段和现场设施，不虚构纪念馆建筑。
